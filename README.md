# 📚 Bookstore Web App

A full-stack **Bookstore Web Application** built using the **MERN stack (MongoDB, Express.js, React, Node.js)**.  
Users can browse, search, and manage books online with a responsive UI.

---

## 🚀 Features
- Browse a catalog of books
- Search and filter books by category, author, or title
- Add, edit, and delete books (Admin functionality)
- User authentication (Signup/Login)
- Responsive design for all screen sizes
- RESTful API integration with MongoDB

---

## 🧰 Tech Stack
- **Frontend:** React, HTML5, CSS3, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Atlas/Local)  
- **Authentication:** JWT (JSON Web Tokens)
